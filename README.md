# 合肥城市学院校企党建互助微信小程序

## 项目简介

本项目为**合肥城市学院校企党建互助**微信小程序（云开发版），基于微信原生框架 + 云开发（CloudBase）构建，适用于微信发布上线。

---

## 功能模块

### 主要模块（首页7个）
| 模块 | 说明 |
|------|------|
| 学校概况 | 学院简介 + 4个二级学院详情子页面 |
| 校企党建互助简介 | 时代背景、六大需求、五大项目 |
| 学校党建思政资源 | 组织/理论/人才资源 |
| 党建思政专家库 | 专家列表（可动态扩充行数） |
| 党建思政精品课程库 | 四类课程体系（可动态扩充） |
| 校企党建互助案例采撷 | 新闻图文列表 + 单篇全文子页面 |
| 党建互助·联系我们 | 五类需求多选 + 表单提交 + 云存档 + 提醒 |

### 底部TabBar（3个附设栏目）
| 标签 | 页面 |
|------|------|
| 首页 | 主页面（含合城动态滚动） |
| 校区地址 | 三校区 + 高德地图导航 + 联系电话 |
| 视见合城 | 学校宣传视频（横竖屏自适应） |
| 媒体链接 | 官网/微信官号/抖音/小红书 |

## 上线前必须完成的配置

### 1. 填写 AppID
编辑 `project.config.json`，将以下内容替换为您的真实 AppID（在微信公众平台获取）：
```json
"appid": "请填写您的AppID"
```

### 2. 创建云环境并填写环境ID
登录微信公众平台 → 开通云开发，创建环境后编辑 `app.js`：
```js
wx.cloud.init({
  env: '请填写云环境ID',  // 替换为实际环境ID，如 prod-1234abcd
})
```

### 3. 部署云函数
在微信开发者工具中，右键点击 `cloudfunctions/submitContact` 文件夹，
选择**上传并部署（云端安装依赖）**。

### 4. 创建云数据库集合
在云开发控制台创建以下集合：

| 集合名 | 用途 | 建议权限 |
|--------|------|------|
| `school_overview` | 学校概况 | 所有人可读 |
| `colleges` | 学院详情 | 所有人可读 |
| `party_intro` | 校企党建简介 | 所有人可读 |
| `party_resources` | 党建思政资源 | 所有人可读 |
| `experts` | 专家库 | 所有人可读 |
| `course_db` | 精品课程库 | 所有人可读 |
| `cases` | 案例采撷 | 所有人可读 |
| `contact_submissions` | 联系表单提交 | 仅管理员可读 |
| `campus_address` | 校区地址 | 所有人可读 |
| `videos` | 视频列表 | 所有人可读 |
| `media_links` | 媒体链接 | 所有人可读 |

### 5. 配置业务域名
微信公众平台 → 开发 → 开发设置 → 服务器域名，添加学校官网等域名。

## 内容管理（通过云数据库）

所有页面内容均通过云开发数据库管理，可在控制台随时编辑更新。

### cases 集合（案例新闻）
```json
{
  "title": "案例标题",
  "summary": "摘要（显示在列表页）",
  "content": "<p>全文HTML内容</p>",
  "coverImage": "https://云存储图片地址",
  "date": "2025-05-01",
  "tags": ["组织联建"],
  "createTime": "服务器时间"
}
```

### experts 集合（专家库）
```json
{
  "name": "张教授",
  "title": "党建方向首席专家 | 教授",
  "expertise": ["思想引领", "党史教育"],
  "intro": "简介内容",
  "avatar": "https://云存储头像地址",
  "sort": 1
}
```

## 发布上线流程
1. 完成以上配置
2. 微信开发者工具 → **上传代码**
3. 微信公众平台 → 版本管理 → **提交审核**
4. 审核通过后点击**发布**
